# git-intro

An introductory project to **Git and GitHub**, completed as part of the **AI Academy at Digital Learning Hub Luxembourg** curriculum.

## Overview

This repository documents the foundational Git concepts and workflows practiced during the early stages of the AI Academy curriculum — version control being an essential skill for collaborative software and data science work.

## Concepts Covered

- **Repository Setup** — `git init`, cloning, and remote connections
- **Staging & Committing** — `git add`, `git commit`, and understanding the working tree
- **Branching** — Creating, switching, and merging branches
- **Remote Workflows** — `git push`, `git pull`, `git fetch`
- **Resolving Conflicts** — Understanding and fixing merge conflicts
- **History & Logs** — `git log`, `git diff`, and navigating commit history
- **Undoing Changes** — `git revert`, `git reset`, and `git checkout`

## Key Takeaways

- The difference between `git clone` and `git remote`
- How to recover from common Git mistakes (mid-merge issues, divergent branches)
- Best practices for commit messages and branch naming

## Tools

- Git (CLI)
- GitHub
- VS Code (with GitLens extension)
